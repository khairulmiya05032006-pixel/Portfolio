# Getting Started with Next.js App Router

The App Router in Next.js introduces a new paradigm for building React applications. Server Components are the default, which means less JavaScript shipped to the browser and faster page loads.

## Key Concepts

- **Server Components** render on the server and send HTML to the client
- **Client Components** use the `'use client'` directive for interactivity
- **Layouts** persist across navigations and maintain state
- **Loading UI** provides instant feedback with React Suspense

## Why It Matters

Server Components let you keep heavy dependencies on the server. Database queries, file system access, and API calls happen at build or request time — never in the browser bundle.
