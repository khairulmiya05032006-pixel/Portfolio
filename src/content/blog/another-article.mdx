# Building a REST API with Express and MySQL

When I built Amana Capital, structuring the backend properly was one of the most important lessons. Here is what I learned about separating concerns in a Node.js application.

## Route → Controller → Service

Keeping route definitions, business logic, and database queries in separate layers makes the codebase easier to test and maintain.

## Error Handling

A centralized error middleware catches all unhandled errors and returns consistent JSON responses. This prevents the server from leaking stack traces to clients.

## Authentication with JWT

JSON Web Tokens provide stateless authentication. Short-lived access tokens paired with refresh tokens balance security and user experience.
